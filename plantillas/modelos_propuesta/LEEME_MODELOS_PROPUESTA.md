# Modelos de Propuesta e Informes Tipo — Geologgia Ltda.

En esta carpeta (`plantillas/modelos_propuesta/`) puedes dejar tus **formatos de propuesta técnica o informes tipo históricos de Geologgia Ltda.** para estandarizar todas las ofertas futuras:

1. **`plantilla_base_geologgia.docx` (Opcional — Membrete y Estilos Word):**
   - Si guardas aquí un archivo Word vacío o con portada/encabezado/pie de página llamado `plantilla_base_geologgia.docx`, el script `armar_propuesta.py` lo tomará automáticamente como documento base para heredar tus logos, márgenes, fuentes y membrete oficial.
2. **Propuestas Históricas Exitosas (`*.docx` / `*.pdf`):**
   - Cualquier propuesta o informe técnico anterior que dejes en esta carpeta servirá como **Guía de Estilo, Estructura de Capítulos y Redacción Técnica** para que el agente **Especialista Técnico** (Habilidades 20 a 28) mantenga exactamente el tono, índice y nivel de profundidad de Geologgia Ltda.
